# Collapsible Creation Bar - Implementation Guide

## USER REQUEST:
"Can we get a toggle for the top game creation bar
and also have it close once the game is created"

## IMPLEMENTATION:

### 1. ADD TOGGLE BUTTON (before creation bar)

```html
<button id="toggleCreationBar" style="
  position: fixed;
  top: 4px;
  right: 4px;
  background: #1a8c3a;
  color: white;
  border: none;
  padding: 8px 12px;
  border-radius: 6px;
  cursor: pointer;
  font-size: 16px;
  z-index: 1001;
">☰ Create/Join</button>
```

### 2. WRAP CREATION BAR IN COLLAPSIBLE CONTAINER

```html
<div id="creationBarContainer" class="creation-bar-container">
  <!-- Your existing creation bar content here -->
  <!-- Name input, player count, CPU count, Create/Join buttons -->
</div>
```

### 3. ADD CSS STYLES

```css
.creation-bar-container {
  max-height: 200px;
  overflow: hidden;
  transition: max-height 0.3s ease-in-out, opacity 0.3s ease-in-out;
  opacity: 1;
}

.creation-bar-container.collapsed {
  max-height: 0;
  opacity: 0;
  pointer-events: none;
}

#toggleCreationBar {
  transition: background 0.2s;
}

#toggleCreationBar:hover {
  background: #0d5f1f;
}
```

### 4. ADD JAVASCRIPT

```javascript
// Toggle button functionality
const toggleBtn = document.getElementById('toggleCreationBar');
const creationBar = document.getElementById('creationBarContainer');
let isExpanded = true;

toggleBtn.addEventListener('click', () => {
  isExpanded = !isExpanded;
  if (isExpanded) {
    creationBar.classList.remove('collapsed');
    toggleBtn.textContent = '☰ Create/Join';
  } else {
    creationBar.classList.add('collapsed');
    toggleBtn.textContent = '☰ Show';
  }
});

// Auto-collapse on game creation
socket.on('game-created', (data) => {
  // ... existing game-created logic ...

  // NEW: Auto-collapse creation bar
  isExpanded = false;
  creationBar.classList.add('collapsed');
  toggleBtn.textContent = '☰ Show';
});
```

## BEHAVIOR:

1. **On Page Load:**
   - Creation bar is visible (expanded)
   - Toggle button shows "☰ Create/Join"

2. **Click Toggle Button:**
   - Creation bar slides up/down smoothly
   - Button text changes: "☰ Create/Join" ↔ "☰ Show"

3. **After Creating Game:**
   - Creation bar automatically collapses
   - Button changes to "☰ Show"
   - User can still re-open if needed

4. **During Gameplay:**
   - Creation bar stays hidden
   - More screen space for cards
   - Can re-open to see room code or create new game

## BENEFITS:

✅ Saves screen space during gameplay
✅ Automatic collapse after game creation
✅ Can still access if needed
✅ Smooth animations
✅ Mobile-friendly
